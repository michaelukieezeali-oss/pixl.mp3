# 🎵 Pixl.mp3

A simple, pixel-inspired music player built with HTML, CSS, and JavaScript.

## ✨ Features

- 🎧 Upload and play your own music.
- ⏯️ Play and pause controls.
- ⏮️ Previous and next track controls.
- 💾 Save your music library using IndexedDB.
- 🎚️ Track progress and playback time.
- 🎵 Automatically manage your uploaded songs.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- IndexedDB

## 🌐 Live Demo

[Listen to Pixl.mp3](https://michaelukieezeali-oss.github.io/pixl.mp3/)

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## 💡 About

Pixl.mp3 is a personal project created to explore web development, JavaScript, audio playback, and browser storage.
